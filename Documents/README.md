# 📊 Financial Sample – Dashboard de Análise Financeira

Este projeto foi desenvolvido utilizando o Financial Sample, um conjunto de dados fictícios disponibilizado pela Microsoft para fins de estudo e prática em ferramentas de Business Intelligence.

O dataset inclui informações como:

- Vendas
- Lucro
- Descontos
- Segmentos
- Países
- Datas
- Categorias de produtos

Esses dados permitem realizar análises financeiras e construir dashboards interativos, representando métricas comuns de negócios, como desempenho por produto, lucratividade, tendências temporais e distribuição por mercado.

## Como utilizar?

Existem duas formas de utilizar o dataset:

Opção 1 – Usar o Financial Sample diretamente pelo Power BI

1. Abra o Power BI Desktop.
2. Na página inicial, clique em “Usar dados de amostra”.
3. Em seguida, selecione “Carregar dados de exemplo”.
4. A janela Navegador será aberta; selecione a tabela “financials”.
5. Clique em Carregar para usar os dados imediatamente ou em Transformar dados para editar antes de carregar.

**Vídeo do passo a passo:**

https://drive.google.com/file/d/1dmCeIrrdGgbcPxbgycDcJ9xc9ObmLkKq/view?usp=drive_link

---
Opção 2 – Usar o arquivo deste repositório

1. Baixe o arquivo disponibilizado neste repositório.
2. No Power BI, clique em “Importar dados do Excel”.
3. Selecione o arquivo baixado.
4. Quando a janela Navegador abrir, escolha a tabela “financials”.
5. Clique em Carregar ou em Transformar dados, caso queira fazer ajustes.
