# 📊 Dashboard – Financial Sample (Power BI)

Este projeto foi desenvolvido utilizando o Financial Sample, um conjunto de dados fictícios fornecido pela Microsoft para fins de estudo.
O objetivo foi realizar análises financeiras e transformar essas informações em gráficos visuais, facilitando a interpretação dos resultados.

No dashboard criado, é possível visualizar métricas como:

- Receita total por país.
- Lucro por segmento.
- Variação de vendas ao longo do tempo.
- Desempenho por categoria de produto.
- Análise geográfica utilizando mapas.
- Comparações entre anos e regiões.

Essas visualizações ajudam a compreender rapidamente o comportamento financeiro dos produtos, tendências e oportunidades de melhoria.

## 📁 Como visualizar o dashboard

Para abrir o projeto no Power BI corretamente, siga os passos abaixo:

1. Baixar o arquivo

**Baixe o arquivo:**

```
dashboard_financial_sample.pbix
```

E abra no Power BI Desktop.

---

**Ativando mapas no Power BI**

Para que os visuais de mapa apareçam corretamente, é necessário ativar a opção de “mapas e visuais de mapa preenchido”.
Siga este passo a passo:

1. No menu principal, clique em Arquivo.
2. Acesse Opções e configurações.
3. Clique em Opções e depois em Segurança.
4. Role até encontrar Mapas e visuais de mapa preenchido.
5. Marque a opção.
5. Clique em OK e reinicie o Power BI.

Após isso, todos os mapas do dashboard serão exibidos normalmente.
