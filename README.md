# 📊 Projeto de Estudo – Financial Sample (Power BI)

Esse projeto foi criado para fins de estudo e para o bootcamp da DIO "Formação Power BI Analyst".
Por meio desse projeto, estou utilizando o Financial Sample para coletar dados, realizar transformações e criar visualizações interativas no Power BI.

Neste repositório você vai encontrar:

O dataset utilizado (Financial Sample)
O arquivo do dashboard desenvolvido no Power BI
Instruções de uso para carregar o dataset
Arquivos complementares (imagens e vídeos do dashboard)
Documentação do projeto

## 📘 Sobre o Dataset

O dataset Financial Sample é um conjunto de dados fictícios fornecido pela Microsoft para fins educacionais.
Ele contém informações financeiras como:

- Vendas
- Lucro
- Descontos
- Segmentos
- Países
- Produtos
- Datas

Esses dados foram utilizados para criar visualizações analíticas e explorar métricas relevantes por meio do Power BI.

## 📈 Dashboard

O arquivo principal do projeto é:

```
dashboard_financial_sample.pbix
```
